手書きの写真から読み取る(AI)Read a handwritten log photo (AI)

紙の作業日誌や加工の記録を撮った写真を、AIが読み取って記録の下書きにします。下書きは「フォームに入れる」で栽培・加工の入力画面に入るので、内容を確かめて直してから「記録する」で保存してください。AIの読み取りは間違えることがあります。AI reads a photo of a paper work log or processing sheet and turns it into draft records. "Put in the form" opens each draft in the Field or Processing entry screen; check and correct it there, then save with "Save record". The AI can misread.

CSVをまとめて取り込むImport CSV files

このアプリで書き出したCSV(作業日誌・加工・格付・洗浄)を、何枚でもまとめて選べます。種類は自動で見分け、取り込む前に件数を確認します。Pick any number of the CSV files this app exports (field log, processing, grading, cleaning) at once. Each file's kind is detected automatically, and the counts are shown for confirmation before anything is added.

  • すでにある記録(同じロット番号、または同じ日・同じ内容)は飛ばします。同じファイルを2回取り込んでも増えません。Records that already exist — same lot number, or same day and same content — are skipped, so importing a file twice adds nothing.
  • Excelで列を並べ替えたり足したりしても読めます。1行目の見出し(「日付 / Date」など)は消さないでください。Columns may be moved or added in Excel; keep the header row ("日付 / Date" and so on).
  • 取り込んだ記録は手で入力した記録と同じ扱いで、次の同期でサーバーに送られます。Imported records are treated like hand-entered ones and go to the server on the next sync.

圃場と機械は、2024〜2025年の有機JAS継続申請書(A-C・A-G)から取り込んだ実データです。所在地・面積・有機管理開始日は原本と照合してからご利用ください。Fields and machines were imported from the 2024–2025 organic JAS renewal applications (forms A-C and A-G). Check the address, area and organic-management start date against the originals before relying on them.

継続申請書の下書きRenewal application draft

記録から A-J(申請圃場の栽培履歴と計画書) を圃場ごとに作り、A-G(機械)・A-C(圃場一覧)とあわせて Excel で書き出します。申請年度は10月〜翌9月です。書式のセル位置は申請書と同じにしてあるので、そのまま提出するか、HOASの様式に貼り付けて使えます。Builds the A-J cultivation history and plan for every applied field, plus the machine and field lists, as one Excel file. The application year runs October to September, and the cells sit where they sit in the official sheet, so the file can be submitted as it is or pasted into the HOAS template.
